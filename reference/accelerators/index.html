    Accelerators¶

    skyward.accelerators ¶

    The accelerator names, as the user spells them.

    sky.accelerators.A100(count=4) is the v1 spelling and it survives, but there is no hand-written factory behind each name: the catalog already knows every accelerator Skyward speaks of, and a module that listed them again would be a second catalog to keep in step with the first. The attribute is resolved against the catalog, so a name that exists here is a name a provider can be asked for.

    __all__ = ['Accelerator'] module-attribute ¶
