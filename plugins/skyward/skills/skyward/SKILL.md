# Skyward

This file is an index. Read the one reference that matches the task, and open another only when the task crosses into it. Paths are relative to this skill's directory.

When this plugin's MCP tools are in the session (`mcp__plugin_skyward_skyward__*`, often listed by name only: load them with ToolSearch), they take the place of the `sky` commands they cover, also in a session that has been running `sky` in a shell. They reach the same daemon in less text: list, read, create, scale, update and delete computes (`list_computes`, `get_compute`, …), run a shell command on the nodes (`exec_command`, not `sky compute exec`), read tasks, the event log, the latest metrics and their history, the daemon's own log, offers and accounts, cancel a task, and run a file that declares its compute as `sky run` does (`run_script`, which answers once the run's task is queued, as `sky run` does; `read_result` reads what its task returned). The CLI keeps what they leave out: files, `ssh`, `repl`, `compute run`, registering an account with `providers set`, starting the daemon, and following output as it arrives (`sky monitor`): after `run_script` or `sky run`, `sky monitor <name>` run as a background monitor (the Monitor tool) brings each event of the run as a notification, and ends once the compute is deleted. The references below show the CLI; with the tools connected, read them for what a command means and call the tool.
